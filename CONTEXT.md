# Local Pages

Local Pages lets an operator choose which content from a Git repository to publish as a website.

## Language

**Page**

A configured website with its own address and a source selected by the operator.

**Source**

The Git provider, repository, branch, publish folder, and entry file selected for a Page.

**Page address**

The editable subdomain where readers open a published Page.

**Directory**

The signed-in view at the base hostname where readers find published Pages.

**Publish folder**

The folder in the selected branch containing the files that make up a Page.

**Entry file**

The HTML or Markdown file readers open when they visit the Page address.

**Reader account**

An individual sign-in that grants access to the directory and all published Pages while the account is active.
