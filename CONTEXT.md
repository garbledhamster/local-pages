# Local Pages

Local Pages lets an operator choose which content from a Git repository to publish as a website.

## Language

**Page**

A configured website with its own address and a source selected by the operator.

**Source**

The Git provider, repository, branch, and entry file or folder selected for a Page.

**Page address**

The editable subdomain where readers open a published Page.

**Directory**

The signed-in view at the base hostname where readers find published Pages.
